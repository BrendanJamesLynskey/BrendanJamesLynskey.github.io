Method

How this is built

I choose the topics, write the specifications and set the rules for verification: every number on these pages comes from tested code or a cited, dated source, every browser port must reproduce its Python reference, and every model is checked against something independent of it. I check the numbers, and I own them.

The building is done with Claude (Anthropic's Claude Code) as an agentic engineering workflow. One session plans the work and writes a brief; another carries the brief out; the first then checks the result against the brief before anything is published. Every commit made this way carries a Co-Authored-By: Claude line, so the split is visible in each repository's history.
